01 · 목적과 데이터

불량 칩의 ‘양’과 ‘배치’를 함께 살폈습니다.

웨이퍼맵은 웨이퍼 위 칩들의 정상·불량 위치를 표시한 지도입니다. 중앙 집중, 가장자리, 선형 등 불량의 배치는 공정·장비 이상 원인의 후보를 좁히는 단서가 될 수 있습니다.

이 프로젝트에서는 사람이 육안으로 판단하는 작업을 보조하도록, 이미지를 입력하면 패턴 종류를 분류하는 모델을 만들었습니다.

none은 ‘특정 결함 패턴이 없는 유형’입니다. 불량 칩이 전혀 없다는 뜻은 아닙니다. 또 패턴 종류가 표시된 데이터 전체를 학습한 것이 아니라, 계산량을 고려해 유형별 표본 수에 상한을 두었습니다.

02 · 문제 발견과 개선

취약했던 선형 결함을 찾아 개선했습니다.

기본 이미지 분류 모델(CNN)은 전체 Macro F1 약 0.80을 기록했지만, 선형 결함인 Scratch의 F1은 약 0.37로 낮았습니다. Scratch와 none의 불량 칩 비율이 모두 약 10%여서, 결함의 양에 더해 공간적 배치를 구분할 정보가 필요하다고 판단했습니다.

개선 가설 · 이미지 축소 과정에서 가느다란 선형정보가 약화됐을 가능성을 고려했습니다. 원본 맵의 위치·분포 정보를 함께 입력하면 분류를 보완할 수 있는지 확인했습니다.

증강 대상은 Scratch·Random·Donut·Near-full·Loc입니다. 회전·반전은 분할 이후 학습 데이터에만 적용했습니다. 결함 종류를 보존한다는 가정을 활용했으며, 원래 방향이 중요한 공정 원인 분석에서는 별도 검토가 필요합니다.

03 · 평가와 핵심 결과

학습에 사용하지 않은 Lot에서도 다시 평가했습니다.

Lot은 생산 과정에서 묶어 관리하는 웨이퍼 집단입니다. 같은 Lot의 웨이퍼는 비슷한 특성을 공유할 수 있습니다. 웨이퍼를 무작위로 섞으면 같은 Lot이 학습과 평가에 모두 포함될 수 있어, 새로운 Lot에서도 잘 작동하는지 별도로 확인했습니다.

평가 방식을 재점검한 이유 · 초기에는 웨이퍼를 무작위로 분할했습니다. Lot 구간에 따라 데이터 분포가 다르고 같은 Lot이 분할 간 섞일 수 있다는 한계를 확인해, Lot 독립 평가를 추가했습니다.
① Lot을 먼저 분리고유 Lot을 번호순으로 나누고, 같은 Lot이 학습·검증·평가에 겹치지 않게 구성했습니다.
② 검증 데이터로 선택4개 조합을 비교해, 공간정보 추가+회전·반전 학습(특징+증강) 조합을 선정했습니다.
③ 별도 Lot으로 최종 평가선택한 조합을 학습+검증 데이터로 재학습한 뒤, 남겨둔 평가 Lot에서 확인했습니다.

Lot 구간별 ‘약 51% / 3–10%’가 의미하는 것

라벨 웨이퍼를 Lot 번호 분포 기준으로 10구간으로 나눴을 때, 앞 2구간에서 결함 패턴으로 라벨된 웨이퍼 비율은 평균 약 51%, 나머지 구간은 약 3–10%였습니다.

이는 웨이퍼 내부의 불량 칩 비율이 아니라, 라벨 웨이퍼 중 none 이외의 유형이 차지하는 비율입니다. 실제 생산 불량률을 뜻하지 않습니다. 분포 차이가 공정 변화 때문인지 라벨링 정책 때문인지는 확정할 수 없습니다.

04 · 한계와 배운 점

모델 개선과 평가 설계를 함께 점검했습니다.

취약 패턴을 찾아 개선 가설을 세우고, 개별 비교 실험으로 효과를 확인했습니다. 이어 새로운 Lot에서 다시 평가해, 점수가 적용되는 범위와 남은 약점을 구분했습니다.

  • 축소의 영향은 가설입니다. 고해상도 조건과 직접 비교하지 않아, 이미지 축소가 Scratch 저성능의 직접 원인인지는 확정하지 못했습니다.
  • 새로운 Lot에서도 약점이 남습니다. 최종 Scratch F1은 0.601이며, Donut 등 다른 취약 유형도 추가 개선이 필요합니다.
  • 패턴 분류까지 검증했습니다. 공정·장비 정보가 없어 실제 이상 원인을 직접 규명하거나 현장 업무 절감 효과를 측정하지는 않았습니다.

전체 흐름은 EDA → 전처리 → 기본 CNN → 공간특징 추가 → 데이터 증강 → Lot 예비 점검 → 무작위 3-way 평가 → Lot 3-way 평가 → Grad-CAM입니다. 예비 Lot 2-way 평가의 0.603은 최종 대표 수치와 구분합니다.

Grad-CAM은 CNN 이미지 경로가 어느 위치에 반응했는지 보여주는 분석입니다. 공간특징 경로의 기여도나 판단 원인 전체를 설명하지는 않습니다.
